# First Stage Scope

This project is currently limited to first-stage target configuration modeling.

- Only toy CGI binaries are supported.
- Analysis must be performed only in authorized environments.
- The first version only models pre-analysis configuration for command injection.
- Real firmware emulation is not supported yet.
- ROP and shellcode are not supported.
- Destructive exploits will not be generated.
- Future PoCs are intended only for harmless marker verification.
